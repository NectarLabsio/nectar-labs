# WO-33b design evidence (Markets, Borrow, Shield, Position)

Files: `{feed,borrow,shield,position}-{1440,400}-{dark,light}.png` (reduced motion, full page, mocked v2 views with the artboard demo numbers as fixtures). Generated by `apps/web/e2e/design-app.spec.ts`.

- `/feed` — differs from Main: the week chart is a schedule from current on-chain values and says so (a Q sparkline is added when the Feed API has history); no Details link (`/feed/[symbol]` is WO-33c); equation card, per-asset table, 1Click and settlement history stay below as Market details.
- `/borrow` — differs from Borrow: "Confirm in wallet" opens the existing sign modal instead of the wallet, because every write must show msg, gas and deposit there; adds a flag-line slider (pre_liq_ltv_bps is part of the msg); Standard is the default.
- `/shield` — same composer with the Weekend Shield preselected; the WO-26b preset cards and the Zap card stay below it, so the page is longer than the artboard.
- `/position/[id]` — differs from Position: no Add collateral tab (nectar-core has no such call); Closed replaces Settled and has no per-buyer table (no view returns the legs); Profit-Lock keeps its WO-26b card inside the tab; DI-1 repays $8,099.51, not the README's $8,099.50, which would leave the fill above the cap.
