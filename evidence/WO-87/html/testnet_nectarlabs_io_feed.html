Cramér limit (PRD §4.2)
Bc = min( LTVc · Vc , (1 − hc) · (Qc + Rc + Dc) )

Config: LTV 70 %, haircut 10 % in session / 25 % weekend, base 40 %.

Vc
collateral units × oracle price (× multiplier on v2)
LTVc
max_nectar_ltv_bps (owner-set ceiling)
Qc
committed quotes: live Pappus quote remainders for the asset
Rc
Nectar Reserve: pooled USDC per asset, deployed on nectar-core-v2; the value is read from get_exit_capacity (r_usd_e6)
Dc
verified DEX depth; 0 outside the market session
hc
base haircut in session, weekend haircut otherwise
